# TalleresLatex
Talleres de latex del grupo universitario de informatica

### 📄 Instrucciones de uso de la plantilla LaTeX
Para emplear la plantilla `template.tex` que se encuentra en el directorio **`LaTeX_I-2025`**, es necesario **descargar también la carpeta `resources`**.
> 💡 **Aviso:**  
> Si estás utilizando **Overleaf**, debes **subir ambos archivos (la plantilla y la carpeta `resources`)** al proyecto.  
> Es posible que debas **corregir la ruta de la carpeta donde se encuentra el logo de la UVa**, dependiendo de cómo esté organizada tu estructura de carpetas.
